# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good faith, and keep discussion about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

Report problems privately through GitHub's private reporting on this repository. Maintainers will review every report and may warn, suspend or ban participants.
